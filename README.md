# Flippy

Flippy – учебное веб-приложение для автоматического создания карточек в формате "вопрос-ответ" из pdf конспектов.
Проект разрабатывается в рамках курса Fullstack в виде нескольких лабораторных работ, где каждая расширяет возможности приложения.

## Назначение

Flippy помогает студентам быстрее готовиться к занятиям и экзаменам. 
Пользователь загружает pdf-конспект, после чего приложение создает набор учебных карточек для повторения материала.

## Основные пользовательские сценарии

### Загрузка материала

Пользователь выбирает pdf-файл и добавляет его в список учебных материалов.

### Работа с карточками

Пользователь открывает материал, просматривает вопросы и ответы, а также может добавлять, редактировать и удалять карточки.

### Обучение

Пользователь запускает режим обучения, открывает ответы и переключается между карточками.

## Основные экраны

- **Мои материалы** — загрузка pdf и список добавленных материалов.
- **Карточки материала** — просмотр и редактирование вопросов и ответов.
- **Режим обучения** — последовательное изучение карточек и отображение прогресса.

## Маршруты

- `/` — мои материалы;
- `/documents/:id` — карточки выбранного материала;
- `/documents/:id/study` — режим обучения.

## Лабораторная работа №1

В первой лабораторной работе реализуется интерфейс приложения и каркас
frontend.
На этом этапе используются демонстрационные данные. Реальная отправка и
обработка PDF, сохранение данных и AI-генерация карточек пока не реализованы.
